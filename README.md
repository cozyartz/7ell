# 7ell

**7ell** is a modern, fast, and customizable storefront built with [Astro](https://astro.build/), powered by [Crystallize](https://crystallize.com/) for product content, and using [Square](https://squareup.com/) for secure checkout and payments.

Designed with a clean, dark, and smokey UI — 7ell is built to help you list, showcase, and sell physical products across multiple platforms efficiently.

---

## 🚀 Features

- ⚡️ Astro frontend for high performance and SEO
- 🧱 Crystallize for product catalog (headless PIM)
- 💳 Square checkout integration (via REST API)
- 🎨 Tailwind CSS with a dark, smokey aesthetic
- 🧪 Ready for deployment via Cloudflare Pages
- ⚙️ Automation-ready (Procesio, Robomotion, or Node.js)

---

## 🧩 Tech Stack

| Layer         | Tool / Platform     |
|---------------|----------------------|
| Frontend      | Astro + Tailwind CSS |
| Product Data  | Crystallize (GraphQL)|
| Payments      | Square (Checkout API)|
| Automation    | Robomotion / Procesio / Node.js |
| Hosting       | Cloudflare Pages     |
